## 📌 Featured Projects

### [Vela](https://github.com/parranopolis/vela) — AI-Powered CRM for Retail Sales

*Built after identifying a real gap at Helzberg Diamonds where client intake still ran on handwritten paper forms.*

**Stack:** Next.js · TypeScript · Tailwind CSS · Firebase (Auth + Firestore) · Gemini Vision API · Vercel

**Key Features:**

- **AI Data Extraction** — Gemini Vision API reads handwritten intake sheets from photos and extracts structured client data
- **Human-in-the-Loop** — Review step before any data is saved, ensuring accuracy
- **Smart Dashboard** — Dynamically calculated appointment states (Today / Pending Callback / Follow Up) computed at query time — no scheduled jobs needed
- **Cursor-Based Pagination** — Flat Firestore read costs regardless of client volume
- **Co-Owner System** — Shared accountability across up to 3 sales associates per client
- **Duplicate Detection** — Prevents redundant client entries
